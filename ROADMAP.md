# 🚀 Projeto SaaS - Distribuidora Fácil

## Objetivo Geral

Criar um sistema SaaS para pequenas distribuidoras de bebidas com:

* Controle de estoque
* Cadastro de clientes
* Registro de vendas
* Controle de fiado
* Dashboard gerencial
* Login de usuários
* Multiempresa
* Recursos de IA
